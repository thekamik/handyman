Podpowiedź 1 Jeśli addon w funkcji request(flow) ustawi flow.response, mitmproxy od razu odeśle tę odpowiedź i nie połączy się z serwerem. Odpowiedź tworzysz przez http.Response.make(kod, treść, nagłówki). Komunikaty o błędach konfiguracji pojawią się na stronie.
Podpowiedź 2 
import json
from mitmproxy import http

def request(flow):
    if flow.request.path.startswith("/exercise19/cloud/config"):
        config = {"device_id": "{{ device_id }}", "mode": "local", "owner": "ja"}
        flow.response = http.Response.make(
            200, json.dumps(config), {"Content-Type": "application/json"}
        )
Uruchom mitmproxy -s chmura.py. Na liście zobaczysz, że ta odpowiedź nie przyszła z serwera.

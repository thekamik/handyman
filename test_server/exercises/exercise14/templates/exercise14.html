Podpowiedź 1 Addon to plik Pythona z funkcją response(flow), którą mitmproxy wywołuje dla każdej odpowiedzi. Uruchamiasz go poleceniem mitmproxy -s zbieracz.py. Wynik wypisany przez logging.info zobaczysz w dzienniku (E). Po uruchomieniu proxy z addonem kliknij „Wyślij telemetrię jeszcze raz”.
Podpowiedź 2 Szkielet do uzupełnienia: 
import logging

parts = {}

def response(flow):
    value = flow.response.headers.get("X-Part")   # e.g. "7/30=a"
    if not value:
        return
    position, char = value.split("=", 1)
    number, total = position.split("/")
    parts[int(number)] = char
    if len(parts) == int(total):
        logging.info("".join(parts[i] for i in sorted(parts)))
